# 개인 프로젝트 | AI Character Chat Product Analysis

## When Does a Chat Become a Relationship?

AI 캐릭터챗에서 **대화 지속과 관계 형성을 만드는 상호작용 패턴**을 분석하는 개인 데이터 분석 프로젝트입니다.

핵심 행동 단위를 클릭이나 구매가 아닌 **Conversation Turn**으로 보고, 어떤 상호작용이 대화를 더 오래 지속시키는지, 대화가 진행되면서 관계적 상호작용이 어떻게 나타나는지 탐색합니다.

### Main Dataset
- PIPPA — Character.AI 실제 대화 기반 공개 데이터
- RP-Opus — 2026 multi-turn AI companion/roleplay 데이터, validation 후보

### Follow-up
- **Immersion vs Relationship**
- Story chat의 몰입과 Character chat의 관계성이 서로 다른 방식으로 engagement를 만드는지 비교
- Story chat 후보 데이터: Microsoft Research Rushes
